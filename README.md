# Endless Map

**[Download on CurseForge](https://www.curseforge.com/wow/addons/endless-map)** · **[Watch the video](https://www.youtube.com/watch?v=KgaUoFabvK0)** · [Report a bug](https://github.com/rhadlock/EndlessMap/issues/new?template=bug_report.yml)

[![The Map Blizzard Should Have Made | WoW Forever Endless Map - watch it on YouTube](https://img.youtube.com/vi/KgaUoFabvK0/maxresdefault.jpg)](https://www.youtube.com/watch?v=KgaUoFabvK0)

A seamless world map for World of Warcraft - retail and WoW Forever: one smooth zoom from the whole world to every
zone, city and cave, every portal and boat with where it goes, real minimap terrain, and a map that follows you and
your party.

The CurseForge app installs it and keeps it up to date. The zips are also under
[Releases](https://github.com/rhadlock/EndlessMap/releases).

## Which download

| Game | File | Its folder in `Interface\AddOns` |
|---|---|---|
| WoW Forever, Classic Era | `EndlessMap-Forever-<version>.zip` | `AzerothUnrolled` |
| Retail | `EndlessMap-Retail-<version>.zip` | `EndlessMap` |

## Found a bug?

In the game (from 1.6.1): map menu > **Report a bug**. Copy the report and the form link, open the link and paste the
report - the game and the add-on's version are already filled in. Or open the
[bug form](https://github.com/rhadlock/EndlessMap/issues/new?template=bug_report.yml) here.

## This repository

`AzerothUnrolled/` is the add-on's source: one folder for both games - the retail download is made from it. It keeps
the add-on's first name, Azeroth Unrolled, because the game names your saved settings after that folder. Each version
is one commit, tagged. What changed: [CHANGELOG.md](AzerothUnrolled/CHANGELOG.md) (WoW Forever and Classic Era) and
[CHANGELOG_Retail.md](AzerothUnrolled/CHANGELOG_Retail.md) (retail).
